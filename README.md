# 정책평가팀 HR관리앱

OneDrive 팀서무 폴더의 엑셀을 읽어 보여주는 로컬 웹앱입니다.

## 실행
`HR앱 실행.bat` 더블클릭 → 브라우저에서 http://127.0.0.1:8765 이 열립니다. (창을 닫으면 종료)
필요: Python 3, `pip install openpyxl`

## 데이터 연결
| 메뉴 | 원본 |
|---|---|
| 대시보드 · 휴가관리 | `[평가팀] 2026년 연차 일정.xlsx` › `연차입력` 시트 (이름/시작일/종료일/구분/비고) |
| 주간업무관리 › 주차별 보기·업무영역별 추이 | `[평가팀] 2026년 주간업무계획.xlsx` › 주차별 시트 전체 (맨 앞 시트 = 최신) |
| 주간업무관리 › 개인별 업무 | `[내부용]정책평가팀 주간업무보고.xlsx` › 주차별 시트 (시트명 괄호 속 기간으로 정렬, 업무 없는 양식 시트 제외) |
| 협의검토관리 | 사전협의 검토현황 대시보드(https://kosievalteam.github.io/newbiz_dashboard/)를 화면 안에 표시 |
| 공지사항 | 앱에서 작성 → `data/notices.json` 저장 |

엑셀을 저장하면 앱이 파일 수정시각을 보고 다시 읽습니다(‘엑셀 새로고침’ 버튼, 탭 복귀 시, 5분마다).

## 연차 입력 규칙 (구분 열)
- `연차` 1일 / `오전반차`·`오후반차` 0.5일 / `시간단위휴가(10:00~14:00)` 시간÷8
- `공가(…)` 차감 없음, `대외활동(…)`·`출장` → 근무현황에서 ‘출장·외부활동’
- 여러 항목은 쉼표로 구분: `시간단위휴가(10:00~13:00), 대외활동(13:00~15:00)`
- **구분이 비어 있는 행은 공휴일**로 처리 (예: 제헌절, 대체휴일)
- 주말·공휴일은 기간 계산에서 제외

## 웹 배포 (GitHub Pages)
- `배포.bat` 실행 → 엑셀을 읽어 `docs/data.enc`(팀 비밀번호로 AES-256 암호화)를 만들고 GitHub에 푸시합니다. 1~2분 뒤 웹에 반영됩니다.
- 웹에서는 비밀번호를 입력해야 열립니다. 저장소에는 암호문만 올라가며, 아래 파일은 `.gitignore`로 제외됩니다.
  - `.secret/password.txt` 팀 비밀번호 / `config.json` 팀원 명단 / `data/` 공지 원본
- 비밀번호 변경: `.secret/password.txt` 내용을 바꾸고 `배포.bat` 실행 → 팀원에게 새 비밀번호 공유
- 웹은 보기 전용입니다. 공지 작성·수정은 이 PC의 `HR앱 실행.bat`에서 한 뒤 배포하면 반영됩니다.
- 자동 갱신: Windows 작업 스케줄러 `정책평가팀 HR 웹배포`가 평일 09:00·13:00·18:00에 `배포.bat /auto`를 실행합니다(PC가 켜져 있어야 함).

## 설정 (`config.json`)
- `members[].total`: 2026년 부여 연차일수 → 입력하면 잔여 연차 계산
- `members[].prior_used`: 엑셀에 기록되기 전(7월 이전) 이미 사용한 일수
- 엑셀 경로·포트 변경도 여기서
